Program Modifications:

The script pivplot.m has been modified to account for the larger image size (otherwise the center of the image relative to the wire gets scrambled) and the time base on line 67 has been changed to 1/60 rather than 1/30.  Because of the way the code is written, it will still work with the older video files (which had the 1/30 frame rate), but the velocities will be off by a factor of two until it is changed back.

Camera Modifications:

Under Menu / Image Quality/Size:

Frame Rate should be 60p

File Format should be XAVC S HD

Mp4 file location:

After connecting the usb cable from the computer, two disk images pop up on the desktop.

The files are in the disk NO NAME, folder PRIVATE, subfolder M4ROOT, subfolder CLIP

The .MP4 files should be dragged to appropriate directory on the desktop and renamed (leaving the .MP4 part unchanged) to have the appropriate basename.

Remember to eject the two disk images prior to disconnecting the computer usb cable from the camera.  Camera operation can be restored by x'ing out the USB Connect and then tapping the camera icon in the lower left hand corner.  The usb cable from the computer to the camera is replaced with the camera remote.
